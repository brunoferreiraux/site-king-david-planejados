# King David Planejados

Site institucional desenvolvido para a King David Planejados — móveis planejados sob medida em Barueri, Alphaville e região (SP).

## Tecnologias

- HTML
- CSS (Tailwind CSS via CDN)
- JavaScript

## Estrutura

Página única (`index.html`) com cabeçalho fixo, home, quem somos, produtos e serviços, galeria de projetos do Instagram, avaliações do Google, mapa e rodapé.

Os dados editáveis (WhatsApp, horários, produtos, avaliações e publicações do Instagram) estão centralizados no bloco `CONFIG`, no início do `<script>` ao final do arquivo.
